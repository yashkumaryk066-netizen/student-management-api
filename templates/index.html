Frequently Asked Questions

How secure is institutional data? +
Y.S.M AI uses military-grade end-to-end encryption. All student and financial records are stored in encrypted neural clusters with automatic daily backups.
Can we migrate data from our old ERP? +
Yes, we provide specialized migration tools for CSV/Excel data. Our technical team also assists in manual migration for enterprise clients at no extra cost.
Is training provided for teachers? +
Every plan includes 24/7 video tutorials and a dedicated success manager who will conduct virtual workshops for your staff.
Does it work offline? +
The core system is cloud-based for real-time sync, but our Progressive Web App (PWA) allows offline attendance marking which syncs as soon as internet is available.
